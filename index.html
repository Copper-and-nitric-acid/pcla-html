00 / 起点

市面上的“一键优化”常常只是在猜。

PCLA 想做的，是先用数据读懂你的设备，再给出真正跑得动的配置。它不承诺魔法，只把测量结果摊开给你看。

01先测量，再建议
02先降渲染距离，再动别的
03不吹“优化”，只拿数据说话
01 / 能力

一个启动器，
该做的事都做了

从读懂 GPU 到下载校验，PCLA 把移动端启动器最容易含糊带过的部分，做成了可以看见的工程。

01

先读懂手机，再决定怎么跑

通过 EGL14 离屏上下文静默读取 GPU 型号与可用内存，不需要额外权限，也不会打断你正在做的事。

GL_RENDERER EGL14 NO PERMISSION Mali-G57 MC2
02

下载不是把进度条画出来

多文件队列、自动换源、SHA-1 校验、遇到 429 就自适应降并发。下载这件事，应该稳到不需要你盯着。

PCLA_Alpha0.1.0.apk100%
fabric-loader.jar64%
1.30 MB/s镜像 B · 已切换
03

卡顿，要有证据

解析 -Xlog:gc，输出 STW 的 p50 / p95 / p99 与停顿簇。到底卡在哪，不再靠感觉。

04

降级，也有顺序

掉帧时先降渲染距离；只有内存真的吃紧，才会缩小堆。先保住画面，再谈别的。

RD 8 → 6 → 4 HEAP 只在内存吃紧时

胶囊页签、蓝色主题、克制的圆角。它看起来像你熟悉的那个启动器，但为拇指重新排过版。

02 / 读懂手机

不猜配置，
先做一次体检

启动器会在后台建立 EGL14 离屏上下文，读取 GL_RENDERER、GPU 型号和可用内存，再结合真机基线给出一组默认值。

  • 静默探测：不弹权限、不打断当前界面。
  • 真机基线：天玑 700 + 8 GB 实测，推荐堆 2048 MB、渲染距离 4、首选 1.16.5。
  • 能解释：每个默认值都能追溯到测量，而不是“玄学优化”。

06 / 问题

你可能
还想知道

还有别的问题？去 GitHub Issues 开一条，作者会看到。

打开 Issues

PCLA 是第三方、非官方项目，界面与交互向桌面版 PCL 致敬，但与龙腾猫跃及 PCL 官方没有隶属关系。项目代码以 AGPL-3.0 开源。

不需要。安装包里已经带了 Java 8 与 Java 17 运行时，第一次启动不用再找 JDK，也不用配环境变量。

需要 Android 8.0 及以上、arm64-v8a 架构的 64 位设备。32 位设备暂时无法安装。性能较弱的机器建议先用体检推荐的档位。

Alpha 阶段没有上架应用商店，系统会提示“未知来源”。在确认安装包来自本页面的 GitHub 仓库后，允许本次安装即可。Play Protect 也可能对 debug 构建发出警告。

Alpha 阶段的发布方式不固定，部分构建会以 ZIP 打包 APK。解压后得到 .apk 文件，再点击安装即可。

免费，代码以 AGPL-3.0 开源。作者在爱发电接受自愿赞助，不影响任何功能。

优先到 GitHub Issues 搜索是否已有相同问题；没有的话，附上机型、Android 版本、PCLA 版本和复现步骤开一条新 issue。
